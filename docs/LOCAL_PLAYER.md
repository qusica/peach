# 本机播放器与浏览器播放

Peach 仍以网页直接播放为默认方式。对浏览器声明支持的 HEVC/H.265 MP4，播放计划优先使用 HTTP Range 直接发送原始视频，不启动 FFmpeg 转码。对不兼容的格式保留原有转码与 HLS 回退。

## 本机打开

视频详情侧栏的 **用本机默认播放器打开** 是显式点击操作。仅浏览器以 localhost / 127.0.0.1 / ::1 访问同一台运行 Peach 的电脑时显示并允许调用。

- Windows: 文件关联的默认播放器（例如将 PotPlayer 设为默认）。
- macOS: 系统 `open`，交给默认应用。
- Linux: 有图形桌面会话时执行 `xdg-open`。

浏览器和 Peach 分处两台机器、NAS 容器或公网 Tunnel 时不显示本地播放器按钮；可以使用现有的「外部播放器 / VR」生成网络链接。该按钮只接受馆藏 asset id，不接受用户输入的文件路径或可执行命令。

卡片悬停预览发送 `preview=1`，不兼容的视频返回 HTTP 415，不会因鼠标悬停而整片转码写入 `generated/transcodes`。

浏览器 HEVC 探测为能力提示，不等于保证每种 Profile/Level 的视频都能正常播放；解码失败时仍可使用其他方式。
